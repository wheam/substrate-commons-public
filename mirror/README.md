# mirror — 实例的公开同步网页（可选组件）

给**用不了 MCP 的工具和人**（ChatGPT、豆包、手机浏览器……）一个持链接可读的网页：定时从一个 substrate-commons 实例读取已发布版本，脱敏后生成网页、Agent 全文与 JSON。实例有新提交后约一分钟内同步。

它是**独立的服务**，不在引擎里加任何未认证的路由；对引擎来说它只是一个持只读凭据的普通客户端。

> **先想清楚**：无需登录 + 自动同步，意味着成员写进正文的内容约一分钟后就公开。下面的规则只认得固定格式的号码、链接和一批健康类关键词，认不出没有固定格式的隐私。只有在实例的写作约定明确告诉成员“内容会公开”、并由主人接受这个残余风险时才部署。

## 入口

| 路由 | 内容 |
|---|---|
| `/` | 人读网页（目录 + 全部页面，站内链接与 `#片段` 改成本站锚点） |
| `/trip.md`、`/trip.txt`、`/llms-full.txt`、`/download/trip.md` | Agent 全文（同一内容，类型不同；download 带附件头）。每页前有一行可见的“页面：路径 · 最后修改”；站内链接改成“「标题」页（路径）”的文字引用，免得 AI 跟着点到不存在的网址 |
| `/part/N.md` | 单独一页（N 从 1 开始，按全文目录顺序），给读网页会截断的 AI 分页读取；开头有数据版本和页面路径，结尾有“本页结束”标记 |
| `/trip.json` | `{schema, title, instance, commit_rev, generated_at, redaction, page_count, pages:[{path, title, held, part_url, last_modified, markdown}], sync:{stale, …}}` |
| `/llms.txt`、`/prompt.txt` | 入口说明、可直接转发给 AI 的提示词 |
| `/healthz` | `{ok, disabled, stale, commit_rev, last_auth_ok_at, last_sync_ok_at}`；能提供内容（或已停用）时 200，否则 503；不缓存。Railway 部署健康检查用它：资料库连不上或凭据不对时新版本部署失败，旧版本继续服务 |

`trip` 路由是兼容性名称，也可用于非旅行主题的资料库。所有响应带 `X-Robots-Tag: noindex`；网页的 CSP 是 `default-src 'none'`（无脚本、无图片）。**noindex 不是访问控制**：持有链接的人都能读。

## 安全模型

- **专用只读成员**：镜像的凭据属于一个 `role: reader` 的专用成员（如 `m-public-mirror`），`scope: "read"`。不要挂在真人成员名下：引擎允许一把凭据吊销同一成员名下的其他凭据。
- **每次检查都核对权限**：`whoami` 返回的 scope 不是 `read`，或有效权限超出 `read` / `self_tokens`，立即撤下全部内容并停止。
- **撤下**：
  - admin 用 `token_revoke` 吊销镜像凭据 → 下一次检查（检查间隔 60 秒，加上请求耗时，通常约 1 分钟）或构建途中任何一次请求收到 401，立即撤下，所有内容入口 503；
  - 连续 `AUTH_TTL_MINUTES`（默认 30）没能确认授权（资料库维护、网络中断）→ 同样撤下，直到再次确认；
  - 设 `MIRROR_DISABLED=1` 并重新部署 → 不访问资料库，内容入口 503（不依赖资料库的停用开关；`/healthz` 仍 200，部署能完成切换）；
  - 内容响应 `Cache-Control: no-cache` + ETag，每次回源确认，撤下后缓存不会继续提供。
- **构建在独立线程里跑**：有时限（`BUILD_TIMEOUT_SECONDS`，默认 60）和输入总量上限（`MIRROR_MAX_MB`，默认 16），超时终止线程、这一版不发布；授权检查和网页响应不受影响。
- **授权检查和构建分开**：授权每 `POLL_SECONDS` 检查一次；版本变了才构建。构建按页面 blob 缓存，只重读改过的页；客户端限速每分钟 200 次（引擎默认每把凭据 300 次读），读到一半被限流时，退避后从缓存续上。
- **整批一致**：全部页面按同一个 `commit_rev` 读取，生成后整体替换。
- **同步中断**：超过 `STALE_MINUTES`（默认 5）没有成功同步，网页、`/trip.md`、`/trip.json`（`sync.stale`）、`/llms.txt`、`/prompt.txt` 都标出。
- 凭据启动时校验格式；日志里的凭据一律打码；默认排除 `_commons/`（配置与写作约定）。

## 脱敏规则（src/redact.js、src/doc.js）

原则：宁可多藏。脱敏在 **Markdown 文档树**上做，而不是在原始文字上打补丁：结构规则作用于节点，文字规则作用于“读者看到的连续文字”。

1. **规范化**：解码 HTML 实体；去掉零宽 / 方向控制等格式字符、私用区字符、数字后的组合符号；全角字母数字转半角。
2. **结构规则（作用于节点）**：
   - 敏感字段：`字段：值` 里字段名是（或含）订单号、确认号 / 确认编号、预订号、取票码、票号、电话、手机号、联系方式、邮箱、车牌、证件号、身份证号、护照号、卡号、账号、账户、用户名、微信号、密码（表头和标题里另加身份证、护照、证件），以及 Booking reference、Confirmation、PNR、Phone、Email、Passport no 等英文写法（末尾括注忽略）。以它开头的**列表项整项**（含嵌套的列表、表格、引用；开头被引用包着也算）去掉；写成标题的，标题连同所属小节去掉；段落里的这一行连同懒续行去掉；“字段：”没有值时，本段其余各行和下一块都算它的值（穿过引用向外，到列表项为止）；**代码块**里只要有敏感字段或健康信息就整块不公开（空行、YAML 列表让范围难以可靠划定）。
   - 表格：表头是敏感字段的整列去掉；第一格是敏感字段的行（“字段 | 值”式）整行去掉。
   - 健康等个人话题词（病史、确诊、糖尿病、过敏、怀孕、用药、手术、体检、体重、HIV……）：在标题 → 整节（到同级或更高级标题为止）；在列表项开头 → 整项；在段落行 → 该行（“过敏：”这种空值字段连同本段其余各行和下一块）；在表头 → 整列；在表格行 → 整行；都换成“此处可能涉及健康等个人信息，未公开”。网址里的字母不算。
   - 被去掉的值记进“已隐藏值”（每行第一个词、含数字或 @ 的词、全大写的词、整段值及去掉外层引号后的值、其中的中文词）。
3. **文字规则（作用于读者看到的连续文字）**：同一段里粗体、删除线、链接等标记不占字符，被拆开的号码（`AB**12**CD`、`[139000][x]01111`）按连起来的样子检查；改动映射回原来的文字节点。依次是：
   - 网址：允许的保留且不参与后面的模式，其余换成“［链接已隐藏］”；
   - 通用模式 → `［已隐藏］`：邮箱、手机 / 座机 / 国际 / 美式电话、18 位证件号、分组卡号、车牌、7 位以上连续数字（任何文字的数字）、被空格 / 连字符 / 换行拆开的 9 位以上数字（含日期的除外）、编号形态的字母数字串（6 位以上且至少 2 个数字和 2 个字母，航班号除外）、`sbk_` / `ghp_` / `AKIA` 等凭据、“尾号 1234”；
   - 句中的“敏感字段名：值”（表格单元格、“房间：湖景房；密码：芝麻开门”、“WiFi 密码是…”“PIN=…”，字段名可带括注，入住码 / 门禁码 / PIN 也算）：冒号（或是 / 为 / = / is）后到分句结束的值整段隐藏，支持中文与符号（身份证、护照、证件、电话、手机只在值里有数字时隐藏）；
   - 关键词后面的值：确认号、确认码、PNR、账户、用户名、微信、密码……后面紧跟的第一个值（跳过冒号、强调符号、引号）不论有没有数字都隐藏，形似航班号也不放过；电话、手机等后面同一分句里含 5 位以上数字的值隐藏（分句到 `，。；` 为止）；
   - 无协议的私人文档地址。
4. **链接目标**：只留 http(s)；主机规范化后，IP、无点主机、带用户信息、私人文档 / 网盘 / 短链 / 本服务主机（Google Docs、飞书、Notion、腾讯文档、`*.up.railway.app`……）、主机名里有编号或 7 个以上数字、路径 / 参数 / `#片段`（解码后）里有订单 / 账户 / 令牌字样或邮箱、手机号、车牌、证件号、凭据、编号形态片段、9 个以上数字（UUID 也算）、含任何已隐藏值的链接 → 只留文字加“（链接已隐藏）”。站内相对链接的路径与片段（解码前后）里不能有号码或任何已隐藏值。title 一律去掉。整批先跑一遍收集“已隐藏值”，第二遍才定链接去留。
5. **序列化与复查**：树按固定写法序列化回 Markdown（标题一律 `#`，链接一律内联、目标含括号时用 `<…>`，粗体与删除线保留，斜体和行内代码只留文字，可能构成语法的字符转义）。序列化结果**重新解析**：读者看到的文字必须与树上一致，再复查（去掉允许的网址后不能检出邮箱、手机号、长数字、编号、凭据、车牌、私人文档地址）。不过关的页**这一版不公开**：显示该页上一个公开版本（按本轮规则重新脱敏、页首标明），没有就显示“暂不公开”；其他页照常更新。最后对生成的全文和每个分页**整体**再复查一次，检出就整批不发布。
6. 页面路径、标题、最后修改者显示名、实例名按**纯文字**处理（逐行字段 / 话题 + 文字规则），嵌入 Markdown 时转义；网页锚点只用页面序号和 R01 / H01 这类编号。

**做不到的**（规则的已知限制）：刻意拆成多段的号码（每段都不像号码）；少于 4 位的 ASCII 短密码又原样出现在链接里；JSON 转义写法（\uXXXX）的值又以解码后的样子出现在链接里；超过四层的外层引号；识别没有固定格式的隐私（私人住址、人际关系、话题词之外的健康描述）、故意规避（用汉字写号码、拆成多句）。这类内容不该写进共享库——写作约定里要说明“内容会同步到公开网页”。也会误藏一些公开信息（例如网址带 UUID 的公开 PDF、型号里字母数字混排的词）。

## 配置（环境变量）

| 变量 | 必填 | 说明 |
|---|---|---|
| `COMMONS_URL` | 是 | 实例服务地址（https） |
| `COMMONS_TOKEN` | 是 | 专用 reader 成员的 `scope: "read"` 凭据（`sbk_` + 48 位十六进制）；进程读取后从环境中删除 |
| `PUBLIC_URL` | 建议 | 本站对外地址，写进 llms.txt / prompt.txt；不设时用 `RAILWAY_PUBLIC_DOMAIN` |
| `POLL_SECONDS` | 否 | 授权检查间隔，默认 60 |
| `STALE_MINUTES` | 否 | 多久没成功同步就标出同步中断，默认 5 |
| `AUTH_TTL_MINUTES` | 否 | 多久没能确认授权就撤下内容，默认 30 |
| `MIRROR_DISABLED` | 否 | `1` = 停用：不访问资料库，内容入口 503 |
| `MIRROR_EXCLUDE` | 否 | 不发布的路径前缀，逗号分隔，默认 `_commons/` |
| `MIRROR_PAGE_ORDER` | 否 | 页面顺序，逗号分隔：路径、以 `/` 结尾的前缀、`*`（其余页面的位置）。默认 README 第一、再按 README 里的页面地图。长而次要的页（如餐厅候选）放后面，读网页会截断的 AI 也能先读到要紧的 |
| `MIRROR_PROMPT` | 否 | `/prompt.txt` 的全文，`{url}` 换成 `/trip.md` 的完整地址（已经发给大家的提示词可以原样放这里） |
| `MIRROR_TITLE` | 否 | 站点标题，默认实例显示名 |
| `MIRROR_TIMEZONE` | 否 | 显示时区，默认 `Asia/Shanghai` |
| `BUILD_TIMEOUT_SECONDS` | 否 | 单次构建时限，默认 60 |
| `MIRROR_MAX_MB` | 否 | 单次构建的资料总量上限（含上一版原文），默认 16 |
| `MIRROR_DENY_HOSTS` | 否 | 额外不公开的链接主机，逗号分隔（`COMMONS_URL` 的主机自动加入） |

## 部署（Railway）

1. 用 admin 凭据建专用成员并发只读码：`member_create{member_id: "m-<实例>-mirror", display_name: "公开网页同步（只读）", role: "reader"}`，`invite_create{member_id, client_label: "<实例>-mirror-web", scope: "read", ttl_hours: 1}`；兑换（`POST /enroll`）得到凭据，存进 600 文件，不要显示出来。
2. 新建（或复用）一个**独立的** Railway 服务；用 `railway variable set --stdin COMMONS_TOKEN` 从文件写入凭据，再设其余变量。
3. 从仓库根目录：`railway up mirror --path-as-root --project <项目> --service <服务> --environment production --ci`。
4. 验证：`/healthz` 为 200；逐个入口 HTTP 200；用实例里已知的敏感值（订单号、电话、邮箱）在各入口里搜索，应全部找不到；看日志里“已发布 … 隐藏 …”与有没有“没有通过公开检查”的页。

本地运行：`npm ci && npm test`；`COMMONS_URL=… COMMONS_TOKEN=… node src/server.js`。
